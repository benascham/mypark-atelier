# MyPark – Atelier

Page autonome de l'atelier PC de MyPark (copie de `outils_pc/mypark_admin.html` du projet MyPark2).
Elle ne contient aucune donnée ni aucune clé : l'adresse Supabase et la clé publique sont saisies une fois
(gardées dans le navigateur), puis la connexion se fait par code reçu par e-mail.
